# Axiom TypeScript extension SDK

This package is an npm dependency owned and pinned by Axiom. It exposes no
network, filesystem, process, environment, timer, random, dynamic-loading, or
native-addon API. The generated runner communicates only through bounded
stdin/stdout supplied by the trusted TypeScript kernel and returns the same
typed ABI results consumed by the capability broker.

Application extensions install `@axiomcore/extension-sdk` in their project,
import `defineExtension` from it, and import generated selectors from
`@axiomcore/extension-bindings`. The latter module is generated by the Axiom
CLI for each extension interface.

The working 0.1.2 candidate adds selected finite input/output types and named
continuations. `defineSelectedExtension` comes from the generated bindings.
An export uses `context.complete(value)` or
`context.effects.<continuation>(state, inputs)`; its named `resume` handler
consumes typed branch outcomes. The host performs authorized effects and invokes
a fresh continuation with checked state and replies. Guest heap state is not a
continuation contract.

Selected pure packages use package schema v2 and named-continuation packages use
v3, while the wire ABI remains v1. The initial managed source profile rejects
handles, arbitrary Promise/async work, streams in named continuations and ambient
I/O. Interface generation never adds grants or raises host budgets.

The complete source example is
`examples/advanced-language-dx/selected-extensions/typescript` in the AxiomCore
workspace. Use the exact SDK, generated selection and managed toolchain from
that cohort. These working candidate capabilities do not establish registry
publication or browser/mobile qualification.

# Axiom TypeScript extension SDK

This package is a published npm dependency owned and pinned by Axiom. It exposes no
network, filesystem, process, environment, timer, random, dynamic-loading, or
native-addon API. The generated runner communicates only through bounded
stdin/stdout supplied by the trusted TypeScript kernel and returns the same
typed ABI results consumed by the capability broker.

Application extensions install `@axiomcore/extension-sdk` in their project,
import `defineExtension` from it, and import generated selectors from
`@axiomcore/extension-bindings`. The latter module is generated by the Axiom
CLI for each extension interface.
